OmniOffloader is free and available in the WordPress.org plugin directory.

<Tabs>
	<TabItem label="From the admin">
		<Steps>

		1. In your WordPress admin, go to **Plugins → Add New Plugin**.
		2. Search for **OmniOffloader**.
		3. Click **Install Now**, then **Activate**.

		</Steps>
	</TabItem>
	<TabItem label="Upload a zip">
		<Steps>

		1. Download the zip from [wordpress.org/plugins/omnioffloader](https://wordpress.org/plugins/omnioffloader/).
		2. Go to **Plugins → Add New Plugin → Upload Plugin** and choose the zip.
		3. Click **Install Now**, then **Activate**.

		</Steps>
	</TabItem>
	<TabItem label="WP-CLI">
		```bash
		wp plugin install omnioffloader --activate
		```
	</TabItem>
</Tabs>

After activation, **OmniOffloader** appears in the admin menu. Nothing is uploaded anywhere until you connect a storage provider.

| PHP | 8.1 |

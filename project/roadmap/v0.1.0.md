## Notes

- WP-CLI stubs (`php-stubs/wp-cli-stubs`) added for PHPStan.
- PHPCS ruleset fixed to match the intentional architecture: PSR-4 class-file names excluded from `WordPress.Files.FileName`, vendored `includes/Abstracts/` excluded (kept close to upstream). These sniffs were failing on every pre-existing file too.
- ESLint migrated to flat config (`eslint.config.cjs`, wp-scripts 34 / ESLint 9 ignores `.eslintrc.*`): extends the wp-scripts default; `camelcase` + `jsdoc/require-param` off for TS (REST payloads mirror PHP snake_case by design; TS signatures type every param).
- No separate `Core\Cron` class — `WP_Background_Process` ships its own cron healthcheck for both queues.
